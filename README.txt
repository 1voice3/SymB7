SymB7 – Symbio 700 Service App Simulator (Training Tool)
Source: Trane Symbio 700 Controller User Guide BAS-SVU054C-EN (Nov 2022).
Independent training simulator – not the official Trane app. Always follow the unit nameplate and current Trane documents.

FILES
  index.html               The simulator (single file, works offline; board photo built in)
  manual.html              Manual viewer: opens the guide at a page and highlights the wording
  BAS-SVU054C-EN.pdf       Full manual (original PDF); every "PDF" chip opens it at that page
  SymB7-index.txt          Text copy of index.html
  README.txt               This file
Keep index.html, manual.html and the PDF in the same folder.

INSTALL ON iPHONE (GitHub Pages)
  1. Create a GitHub repo, upload these files to the root, Settings > Pages > Deploy from branch (main /root).
  2. Open https://<user>.github.io/<repo>/ in Safari.
  3. Share > Add to Home Screen.

USING THE MANUAL LINKS
  LEARN tab: each topic has "Guide p.X ↗" (page opens with the wording highlighted) and "PDF ↗" (original PDF at that page).
  They open in the same tab: swipe from the left edge of the screen (or tap ← SymB7) to return to the simulator.

WHAT'S INSIDE
  Launch: BEFORE/AFTER board scene (smoke, LED 10 alarm -> LED 9 normal), 10 seconds, tap to skip.
  Board: real photo, LCD, keypad, Bluetooth lesson (pp.6-9), fault lab, LED locator.
  LEDs, Menu paths (Fig. 30-31), App simulator (Home/Settings/Status/Alarms/Tools, Service Test Mode), Learn, Quiz.
